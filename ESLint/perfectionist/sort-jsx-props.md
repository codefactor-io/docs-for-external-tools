Pattern: Unsorted JSX props

Issue: -

## Description

Enforce sorted JSX props within JSX elements.

Keeping JSX props in a consistent order improves readability and makes them easier to navigate, especially as components grow in complexity.

This rule provides a predictable organization for props, making the code cleaner and easier to maintain while reducing possible errors caused by misplaced or unordered props.

It’s safe. The rule considers spread elements in a props list and does not break component functionality.
