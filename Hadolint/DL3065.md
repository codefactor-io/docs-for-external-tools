Pattern: Redundant `FROM --platform=$TARGETPLATFORM`

Issue: -

## Description

Setting `FROM --platform` to the predefined `$TARGETPLATFORM` is redundant because this is the default behavior. `--platform=$TARGETPLATFORM` is superfluous.

Example of **incorrect** code:

```dockerfile
FROM --platform=$TARGETPLATFORM foo:bar
```

Example of **correct** code:

```dockerfile
FROM foo:bar
```
