Pattern: Sensitive data in `ARG` or `ENV`

Issue: -

## Description

Sensitive data in `ARG` or `ENV` may be persisted in the container image unintentionally.
To avoid this [build secrets](https://docs.docker.com/build/building/secrets/) should be used instead.

Example of **incorrect** code:

```dockerfile
[...]
ARG AWS_ACCESS_KEY_ID
ARG AWS_SECRET_ACCESS_KEY
RUN aws s3 cp
```

Example of **correct** code:

```dockerfile
RUN --mount=type=secret,id=aws \
    AWS_SHARED_CREDENTIALS_FILE=/run/secrets/aws \
    aws s3 cp
```
